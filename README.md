# Shark-Tank-India-Dataset-Creation
A Python-based data collection and cleaning project that creates a structured Shark Tank India Season 1 dataset using Pandas and web table extraction.

## 📌 Project Overview

This project focuses on creating a structured dataset from **Shark Tank India Season 1** using Python and Pandas.

The data was collected from web-based tables and processed to create a clean, structured dataset suitable for analysis and further data analytics projects.

The project demonstrates a practical data preparation workflow, from extracting tabular data to cleaning and validating the resulting dataset.

---

## 🎯 Objectives

The main objectives of this project are:

- Extract tabular data from a web source
- Use Pandas for data collection and processing
- Clean and structure the extracted dataset
- Handle formatting and data-quality issues
- Validate the final dataset
- Export the cleaned data for further analysis
- Create a reusable dataset for data analytics practice

---

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **Jupyter Notebook**
- **Web Table Extraction**
- **Data Cleaning**

---

## 🌐 Data Source

The dataset is based on information from the **Shark Tank India Season 1** Wikipedia page.

The project uses Pandas-based HTML table extraction to collect the required tabular data.
